# Scope Controller v3 — not promoted

**Motivation.** Reduce scope inflation in otherwise focused answers.

**Change.** Added a response profile and an evidence-compatibility gate.

**Observed.** Evidence compatibility corrected some topic mismatches.

**Regression.** Scope/synthesis omitted requested content, token use and latency
increased, and completeness declined.

**Decision.** Not promoted. Production remains on freeze v2. No v3
compatibility-gate or production code appears in the stable path.
